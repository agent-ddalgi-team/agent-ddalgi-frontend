## 1. 요청 사항 및 작업 개요

### 주요 목표
1. **자료 선택·공개데이터·파일추가 기능 완전 복구 및 세션 보장**:
   - 세션 생성 전 비활성화되던 버튼들(`+ 파일 추가`, 드롭존, `공개 데이터 자동으로 가져오기`)의 지연 세션 보장(`ensureSession`) 구현.
2. **참고용 자료 선택 및 실시간 데이터 충족도 연동**:
   - 참고용(Reference) 자료도 체크박스 선택이 가능하도록 활성화.
   - 선택된 자료 목록을 실시간 분석하여 4개 핵심 영역(기업 개요, 공정/설비, 실적, 인증)의 데이터 충족도(0~100%) 동적 산출.
3. **AI 사전 점검 보정 및 클라이언트 세션 격리**:
   - 클라이언트 전용 공개자료 및 참고자료가 백엔드 `POST /inputs` 전송 시 `RESOURCE_NOT_FOUND (404)` 오류를 유발하지 않도록 필터링 및 로컬 영속화 분리.
   - 사전 점검(Preflight) 이후에도 실시간 충족도 점수가 리셋되지 않고 유지되도록 보정.
4. **이미지 전용 자료 UX 개선**:
   - 텍스트가 없는 이미지 전용 자료의 경우 경고(warning)가 아닌 긍정적 안내(info)로 분리 표시하여 사용자 혼선 방지.
5. **코드 품질 및 ESLint 무결성 검증**:
   - `no-useless-assignment` 및 `react-hooks/exhaustive-deps` 린트 오류/경고 100% 해결.

## 3. 상세 수정 내역

### 1) 지연 세션 보장 및 비활성화 해제 (`useSources.ts`, `SourceSelectionView.tsx`)
- 사용자가 명시적으로 '작업 시작'을 누르지 않더라도, 파일 추가나 공개데이터 가져오기 클릭 시 `ensureSession()`을 통해 백엔드 세션을 투명하게 발급하여 기능이 막히지 않도록 개선.

### 2) 실시간 데이터 충족도 알고리즘 연동 (`SourceSelectionView.tsx`)
- 선택된 자료들을 실시간 정규식 분석하여 4대 필수 범주(기업 개요, 제조 공정/설비, 납품 실적, 품질 인증) 충족 여부를 계산.
- AI 점검(Preflight) 결과와 연동하여 사용자가 자료를 추가/제거할 때마다 충족도 게이지 및 누락 카테고리 태그가 즉각 반응하도록 구현.

### 3) 백엔드 세션 유효성 격리 (`useSources.ts`, `sources.ts`)
- 백엔드 DB에 영속화되지 않는 클라이언트 전용 가상 공개자료 및 참고자료의 ID를 `isClientOnlySource()`로 식별.
- 백엔드 `inputs` API 전송 대상에서 제외하고 클라이언트에 안전하게 보존하여 `404 RESOURCE_NOT_FOUND` 예외 원천 차단.

### 4) 이미지 전용 자료 친화적 안내 (`AiWorkflowPanel.tsx`, `profileLabels.ts`)
- 본문 텍스트가 없는 도면/현장 사진 자료에 대해 "내용이 부족합니다" 식의 경고 대신 "초안 문서의 시각 자료 및 갤러리로 적극 활용됩니다" 긍정적 안내 배지로 분리 표출.

### 5) 린트 결함 정리 (`useSources.ts`, `SourceSelectionView.tsx`)
- `useSources.ts`: 미사용 초기값 할당(`let result: Partial<SourceSession> = {}`) 제거.
- `SourceSelectionView.tsx`: `selected = new Set(...)` 인스턴스를 `useMemo`로 감싸 불필요한 렌더링 의존성 변경 경고 해소.
