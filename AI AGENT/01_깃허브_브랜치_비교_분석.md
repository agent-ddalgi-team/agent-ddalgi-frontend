## 4. 각 브랜치 핵심 변경 사항 상세

### 🅰 `codex/clarify-validation-issues` 브랜치의 특징
1. **검증 이슈 위치 표시 및 바로가기 연동**:
   - `DocumentWorkspace.tsx`에서 AI 사전검증(Preflight) 결과 발견된 문제를 해당 블록에 시각적으로 표시.
   - 우측 검증 패널에서 문제 클릭 시 해당 블록 위치로 스크롤 및 포커스 이동.
2. **실제 백엔드 서버 연동 강제 (PR #13)**:
   - 더미 데이터 기반의 Mock 로직을 제거하여, `127.0.0.1:8000` 등 실제 FastAPI 백엔드 세션과의 통신을 필수로 요구함.
3. **사진 콘텐츠 경고 확인/승인 UI (PR #12)**:
   - 사용자가 첨부한 사진에 품질/저작권 경고가 발생했을 때 사용자가 확인 후 승인할 수 있는 워크플로우 추가.

### 🅱 `feature/enterprise-wizard-pdf-export` 브랜치의 특징
1. **웹사이트 및 대형 플랫폼(Google·Naver·Bing) 실사 사진 자동 수집**:
   - **공식 사이트 존재 시**: 메인 및 서브페이지(`/about`, `/facility`, `/product`)를 실시간 크롤링하여 고화질 실사 수집.
   - **공식 사이트 부재 시**: 대형 검색 플랫폼(Google·Naver·Bing) 실시간 검색 엔진을 호출하여 해당 기업의 실제 사진 자동 수집.
   - 링크 변경 시 항상 같은 사진이 나오던 버그 전면 해결.
2. **독립 실행(Standalone) 환경 보존**:
   - 백엔드 서버가 아직 준비되지 않은 환경에서도 프론트엔드 전체 UI/UX를 시연하고 테스트할 수 있도록 Mock 지원 유지.
3. **노션 작업 요약 보고서 보유**:
   - `NOTION_SUMMARY.md` 및 `AI AGENT/` 작업 기록 관리.
