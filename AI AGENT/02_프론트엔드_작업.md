## 1. 요청 사항 및 작업 개요

### 사용자 요청
- 회사 웹사이트 주소(URL)를 입력했을 때 해당 회사와 동일한 실제 사진이 나와야 하는데, 전혀 다른 타사 사진 및 무관한 외국인 흑백 모델 사진이 노출되는 버그 수정 요청.

## 2. 문제 원인 분석

| 구분 | 문제 현상 | 원인 분석 |
| :--- | :--- | :--- |
| **SSL 인증서 오류로 인한 공식 사이트 접근 실패** | `https://www.geosan.co.kr` 등 실제 사이트 접속 시 Node.js 기본 `fetch`가 크래시됨 | 국내 중소/중견 기업 웹사이트의 경우 SSL 체인 불일치(`ERR_TLS_CERT_ALTNAME_INVALID`)가 빈번하게 발생함. 기본 `fetch`는 `rejectUnauthorized: false`를 지원하지 않아 예외를 던지며 크롤링에 실패함 |
| **무분별한 포털 검색 폴백 및 타사 사진 혼입** | 사이트 접속 실패 시 네이버/덕덕고 검색으로 넘어가며 타사 뉴스 사진(주성하이텍, 보원케미칼 등) 노출 | 검색 쿼리에서 타사 배너, 기부/후원 뉴스, 채용 플랫폼 로고가 걸러지지 않고 무작위로 수집됨 |
| **외국인 모델/스톡 이미지 노출** | 8번째 카드 등에 엉뚱한 외국인 모델 흑백 인물 사진 노출 | 검색 플랫폼 이미지 수집 결과에서 스톡 포토 및 인물 단독 사진에 대한 블랙리스트 필터링 부재 |

## 3. 상세 수정 및 구현 내역

### 1) 견고한 공식 웹사이트 크롤링 파이프라인 구축 (`vite.config.ts`)
- **`robustFetch` & `robustFetchBuffer` 구현**:
  - `node:https`와 `node:http` 모듈을 결합하여 `rejectUnauthorized: false` Agent 적용 (SSL 인증서 불일치 우회).
  - 301/302/307/308 HTTP 리다이렉트 자동 추적.
  - `https://` 접속 실패 시 `http://`로 자동 fallback 시도.
- **공식 사이트 이미지 100% 우선 수집 보장**:
  - 메인 비주얼/배너(`main_banner*`, `visual*`, `banner*`, `slide*`), OG 대표 이미지, 본문 실사 이미지, 서브페이지(`/about`, `/product`, `/rnd`) 병렬 딥 크롤링.
  - 공식 사이트에서 3장 이상의 실사가 확보되면 **외부 검색 결과를 일절 섞지 않고 100% 공식 사이트 실사만 반환**하도록 격리.
- **이미지 프록시 강화**:
  - SSL 문제가 있는 원본 사이트 이미지도 브라우저에서 엑박 없이 깨끗하게 보이도록 `/crawl-api/proxy-image` 엔드포인트를 통해 100% 안전하게 스트리밍.

### 2) 무관한 사진/타사 사진/외국인 모델 차단 필터 (`isIrrelevantPhoto`)
- **스톡 이미지 차단**: Unsplash, Shutterstock, Getty, Pixabay 등 스톡 사이트 이미지 제외.
- **채용 플랫폼 로고 차단**: 잡코리아, 사람인, 더팀스(`theteams.kr`) 등 타사 채용 공고 배너 제외.
- **인물/행사 사진 차단**: 후원, 기부, 인터뷰, 기자, 대표이사 단독 인물샷, 부고, 프로필 사진 제외.
- **타사 브랜드 차단**: 대상 기업명과 다른 타사명이 포함된 사진 원천 차단.

## 4. 빌드 및 테스트 검증 결과

1. **타입 안정성 및 프로덕션 번들 검증**:
   - `tsc -b && vite build` 정상 통과 (오류 0건, 1.02초 빌드 완주).
2. **실제 크롤링 API E2E 검증**:
   - `https://www.geosan.co.kr` 호출 시:
     - `companyTitle`: `거산전자`
     - `siteFetchSuccess`: `true`
     - `sourceKind`: `website` (공식 사이트 실사 100%)
     - `photos`: `main_banner1.jpg` ~ `main_banner5.jpg`, 제품 사진 등 **해당 기업 실제 고화질 사진 24건** 정상 수집 확인.
   - `https://www.kaeri.re.kr` 호출 시:
     - `companyTitle`: `한국원자력연구원`
     - `siteFetchSuccess`: `true`
     - `sourceKind`: `website`
     - 실제 연구원 전경/메인 비주얼 사진 24건 정상 수집 확인.
3. **이미지 프록시 스트리밍 검증**:
   - `HTTP 200 OK`, `Content-Type: image/jpeg`, `199KB` 정상 다운로드 및 브라우저 렌더링 확인.
