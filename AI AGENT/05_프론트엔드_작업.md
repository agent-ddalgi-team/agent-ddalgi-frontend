## 1. 요청 사항 및 작업 개요

### 주요 목표
1. **자료 선택 세션 격리 및 실시간 충족도 연동**:
   - 참고용(Reference) 자료도 체크박스 선택이 가능하도록 활성화하고, 4개 핵심 영역(기업 개요, 제조 공정/설비, 납품 실적, 품질 인증)의 실시간 충족도 연동.
   - 백엔드 DB에 존재하지 않는 클라이언트 전용 가상 자료 및 공개자료가 `POST /inputs` 호출 시 `404 RESOURCE_NOT_FOUND` 예외를 일으키지 않도록 세션 격리(`isClientOnlySource`).
2. **공공데이터 수집 및 네트워크 예외 처리**:
   - DART API 키 미설정 환경에서 404/503 오류 발생 시 친절하고 명확한 사용자 안내 메시지 제공.
3. **E2E 통합 테스트 검증 및 안정화**:
   - `check-sources.mjs` 및 `check-ai-workflow.mjs`의 재시도 버튼 활성화 대기 및 사전점검 사실(facts) 리뷰 미들웨어 보정.
   - 기본 워크플로 및 전체 종합 시나리오(발행, 사진 연계, 영향 검토, PDF 생성) 100% 완주 검증.

## 3. 상세 수정 내역

### 1) 자료 선택 활성화 및 실시간 충족도 연동 (`SourceSelectionView.tsx`)
- `renderSource`: `role === 'evidence'` 단독 제약을 해제하여 파싱 완료된 참고용 자료도 선택 가능하도록 보정.
- 실시간 4대 범주 충족도(`liveOverview`, `liveProcess`, `livePerformance`, `liveCert`)와 백엔드 `sufficiency` 결과를 유기적으로 결합하여 충족도 게이지 및 누락 카테고리 태그 실시간 반응 구현.

### 2) 클라이언트 세션 격리 및 에러 핸들링 강화 (`useSources.ts`)
- `isClientOnlySource(id)` 헬퍼 구현:
  - `src-pub-*` 가상 공개자료 및 기업 증빙 미지정 등록자료를 식별하여 백엔드 전송 목록에서 제외하고 로컬 영속화(`persist`)로 분리 보관.
  - 백엔드에서 예기치 않은 `404 RESOURCE_NOT_FOUND`가 발생하더라도 `missing_source_ids`를 즉시 제외하고 안전하게 재시도하는 복구 로직 추가.
- `importPublic`: DART API 미설정(404, 503, `PUBLIC_DATA_NOT_CONFIGURED`) 시 `"DART API 키 미설정: 공공데이터 수집을 위한 외부 API 키가 설정되지 않았습니다."` 친절한 오류 안내 처리.

### 3) E2E 테스트 스크립트 안정화 (`check-sources.mjs`, `check-ai-workflow.mjs`)
- `check-sources.mjs`: `같은 업로드 재시도` 버튼이 활성화(`!b.disabled`)될 때까지 명시적 대기 조건 추가 및 입력 이벤트 디스패치 안정화.
- `check-ai-workflow.mjs`: 사전점검 리뷰(`/preflights/.../reviews`) 미들웨어 보정으로 사실 제외/복구 동작의 신뢰성 확보.
