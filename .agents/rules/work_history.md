# AI AGENT 작업 내역 관리 규칙

## 폴더 위치
- `AI AGENT/` (워크스페이스 및 프로젝트 루트)

## 명명 규칙
- 파일명 형식: `{NN}_프론트엔드_작업.md`
- 번호 `{NN}`: `00`, `01`, `02`, `03`, `04`, ... 와 같이 두 자리 이상 숫자로 1씩 순차 증가
- 새로운 작업을 시작하거나 완료하여 정리할 때는 항상 `AI AGENT/` 디렉터리에 존재하는 파일들을 검색하여 가장 높은 번호의 다음 번호를 부여하여 새 문서를 생성한다.

## 문서 필수 내용
1. 작업 일시 및 작업자
2. 사용자 요청 사항 요약
3. 문제 원인 분석
4. 상세 수정 및 신규 구현 내역 (파일별 코드 변경 요약)
5. 빌드 및 테스트/검증 결과
6. 다음 번호 안내
