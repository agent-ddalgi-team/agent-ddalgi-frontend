## 🎬 상세 시연 대본 및 화면 조작 매뉴얼

### [00:00 ~ 00:45] 1단계: S01 페르소나 원클릭 프리셋

* **화면 위치**: 메인 화면 (S01 소스 및 페르소나 선택)
* **화면 조작**:
  1. 상단 파란색 박스의 **`[🏭 생산기술 담당자]`** 또는 **`[🛡️ 품질 담당자]`** 칩 버튼을 클릭합니다.
  2. 폼 필드(회사 소개 목적, 타깃 청중, 톤앤매너)가 자동으로 완성되는 인터랙션을 보여줍니다.
* **발표 멘트**:
  > "회사소개서는 수신처에 따라 강조해야 할 기술력과 어조가 완전히 달라집니다.  
  > 저희 에이전트 딸기는 복잡한 프롬프트 입력 없이, 상단의 **원클릭 페르소나 프리셋**을 통해 품질/생산기술/영업 등 각 직군에 최적화된 매개변수를 즉시 세팅합니다."
* **기술 소구 포인트**:
  - 사용자 입력 피로도 0% UX
  - 직관적인 마이크로 인터랙션과 프리미엄 뱃지 디자인

---

### [00:45 ~ 01:30] 2단계: S02 실시간 생성 & 무중단 안정성

* **화면 위치**: 하단 생성 버튼 클릭 후 진행 화면
* **화면 조작**:
  1. 하단 우측 **`[선택한 소스로 초안 생성 시작]`** 버튼을 클릭합니다.
  2. 상단 스텝 인디케이터와 중간 진행률 프로그레스 바가 스무스하게 100%로 전환되는 것을 지켜봅니다.
* **발표 멘트**:
  > "단순 텍스트 생성이 아닙니다. 백엔드의 원문 소스 검증, 충분성 평가, 슬라이드 아키텍처 구성이 단계별 파이프라인으로 정밀하게 진행됩니다.  
  > 특히 프론트엔드 전역에 **2중 React Error Boundary**와 백엔드 미구동 시에도 즉시 대체 동작하는 **자체 시연(Demo) 엔진**을 탑재하여, 실시간 네트워크 단절 등 돌발 상황에서도 절대 화면이 멈추지 않는 엔터프라이즈급 내구성을 갖추었습니다."
* **기술 소구 포인트**:
  - Graceful Degradation (우아한 장애 복구 메커니즘)
  - 상단 헤더 원클릭 `[🧪 시연 모드]` 토글러

---

### [01:30 ~ 02:30] 3단계: S03 워크스페이스 & 원문 근거(EvidenceRef) 대조

* **화면 위치**: S03 문서 워크스페이스 화면
* **화면 조작**:
  1. 좌측 슬라이드 카드 중 아무 **텍스트 블록**을 클릭합니다.
  2. 우측 인스펙터 패널에 노출되는 **[원문 근거 (EvidenceRef)]** 카드와 **[Fact ID: #fact-...]**를 가리킵니다.
  3. 키보드로 **`Ctrl + S`**(하단에 '임시 저장 완료' 토스트 발생)를 누르고, **`→` 방향키**를 눌러 다음 슬라이드로 스무스하게 이동합니다.
* **발표 멘트**:
  > "에이전트 딸기의 가장 핵심적인 차별점은 바로 **'근거 중심의 투명성(Explainability)'**입니다.  
  > AI가 생성한 각 슬라이드 본문을 클릭하면, 우측 인스펙터에서 이 문장이 어떤 사내 원본 문서와 팩트 ID를 근거로 작성되었는지 실시간으로 대조할 수 있습니다. 할루시네이션(환각)을 원천 차단한 것입니다.  
  > 또한 발표자와 실무자의 작업 편의를 위해 `Ctrl+S`, 슬라이드 방향키 넘김 등 실전 단축키를 완벽 지원하며, 실수로 브라우저를 닫아도 **세션 자동 보존 엔진** 덕분에 편집 내역이 100% 복구됩니다."
* **기술 소구 포인트**:
  - RAG 신뢰성 시각화 (EvidenceRef 인스펙터)
  - `sessionStorage` 기반 무손실 편집 복구 엔진 (`usePublication`)
  - 키보드 내비게이션 단축키 및 반응형 하단 독
