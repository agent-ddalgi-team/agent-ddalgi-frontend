# 발표 시연 참고 대본

기준: 2026-10-12 현재 프론트 코드. 발표 구성 참고용이며 실제 AI 품질·운영 보안 검증 결과가 아니다. [현재 상태](../WORK_SUMMARY.md)와 [보안 대조](../security/BACKEND_SECURITY_REQUIRED.md)를 우선한다.

| 시간 | 시연 흐름 | 설명할 내용 |
|---|---|---|
| 0:00~0:45 | 회사·작성 조건·자료 선택 | 사용 목적과 자료를 지정한다. 충족도 숫자에는 파일명/개수 추정이 섞이므로 실제 AI 판단이나 승인 통과율로 소개하지 않는다 |
| 0:45~1:30 | 점검·초안·편집 | 실제 모드에서는 서버가 필요하다. 가상 시연은 화면 흐름만 보여 주며 실제 AI 결과와 구분한다 |
| 1:30~2:30 | 발췌 근거·검증·정정 기록 | 문장에 연결된 출처/발췌문을 비교한다. 오타 정정은 사유/근거 기록 후 재검증이며 자동 통과가 아니다 |
| 2:30~3:00 | 출력·제한 안내 | 실제 파일은 서버 승인 출력 경로를 사용한다. 즉시 PDF는 고정 자료의 별도 생성 경로로 현재 검증 문서 출력과 다르다 |

## 발표 전 확인

- `?preview=1`은 명시적 가상 시연이다. 실제 모드는 이 값을 제거하고 백엔드를 별도로 실행한다. 가상 화면을 실제 서버 완료 증거로 사용하지 않는다.
- 실제 자료나 유료 AI 생성은 별도 허용된 검수 범위에서 준비한다. 이번 문서 정리는 해당 호출을 실행하지 않았다.
- 서버 장애를 시연 모드로 바꾸는 것은 실제 작업 성공/승인으로 복구한 것이 아니다.
- 블록의 발췌문 표시와 전체 추출문/원본 조회는 다르다. 현재 프론트에는 후자의 API 연결이 없다.
- 단축키·버튼·레이아웃은 발표할 빌드에서 직접 확인한다. 과거 대본의 고정 프리셋 이름이나 클릭 순서를 현재 UI에 있다고 가정하지 않는다.

| 질문 | 현재 코드 기준 설명 |

| 새로고침 시 편집은 보존되는가? | edits/removed를 sessionStorage JSON으로 저장해 복구를 시도한다. 암호화가 아니며 저장 오류·탭 종료 등의 상황에서 무손실 복구를 보장하지 않는다 |

| 장애가 발생해도 항상 동작하는가? | 오류 안내·재시도·별도 가상 시연 경로가 있다. 모든 장애의 자동 복구나 무중단을 보장하지 않는다 |
